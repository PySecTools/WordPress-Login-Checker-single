## 🔍 Description

**PySecTools – WordPress Login Checker** is a desktop application designed for security professionals and ethical hackers to **test the validity of WordPress login credentials** in a controlled and authorized environment.

It uses a **cookie-based detection mechanism** to determine whether a given username/email and password combination is valid, avoiding unreliable HTML scraping. The tool comes with a sleek **dark "hacker" theme**, real-time console logging, and response time measurement.

> ⚠️ **This tool is for authorized penetration testing and educational purposes only. Use only on systems you own or have explicit permission to test.**

---

## ✨ Features

- 🎯 **WordPress Login Testing** – Validates credentials via `/wp-login.php` and cookie analysis.
- 🍪 **Cookie-Based Detection** – More reliable than checking HTML error messages.
- ⚡ **Fast & Concurrent** – Uses Go’s lightweight goroutines for non-blocking UI.
- 📜 **Real-Time Console Log** – Timestamped logs with status updates.
- ⏱️ **Response Time Measurement** – See how long each request takes.
- 🔌 **Connection Tester** – Verify target reachability before attacking.
- 🧪 **Multi-Tab Interface** – Target input, console log, and help sections.
- 🌙 **Dark / Hacker Theme** – Neon green on deep black background.
- 🔗 **Telegram Channel Link** – Built-in link to @PySecTools.
